Що таке Git?

Git — это найпопулярніша у світі розподілена система контролю версій. Вона дозволяє фіксувати зміни у файлах коду, відкочуватися до попередніх версій проекту та вести розробку паралельно за допомогою гілок.

Оскільки система розподілена, кожен розробник має на своєму ПК локальну копію всієї історії проекту, що гарантує високу швидкість та повну незалежність від сервера.

Переваги використання Git

  • Локальна швидкість: комміти та перегляд історії відбуваються миттєво без інтернету.
  • Потужне розгалуження: легке створення ізольованих гілок для кожної нової фічі.
  • Надійність: захист даних за допомогою унікальних хешів SHA-1.
