Що таке системи контролю версій та Git?

Система контролю версій (VCS) — це софт, який фіксує зміни у файлах проекту з плином часу. Завдяки цьому можна повернутися до будь-якого попереднього стану коду, подивитися, хто саме зробив помилку, або паралельно розробляти нові фічі, не ламаючи основну версію продукту.

Git — це найпопулярніша сьогодні розподілена система контролю версій. Її створив Лінус Торвальдс (автор Linux). "Розподілена" означає, що кожен розробник має на своєму комп'ютері повну копію всієї історії проекту, а не просто завантажує файли з одного центрального сервера.

Головні переваги Git

  • Швидкість роботи: майже всі операції відбуваються локально на комп'ютері, тому немає затримок через інтернет.
  • Зручне розгалуження (Branching): можна створити окрему гілку для експериментів, а потім легко злити її з основним кодом.
  • Надійність: кожен комміт має унікальний хеш (SHA-1), що унеможливлює непомітну зміну чи пошкодження файлів.
  • Робота в команді: Git дозволяє тисячам людей одночасно працювати над одним проектом без хаосу.

10 базових команд Git для щоденної роботи

Команда Що вона робить (коментар)
git init Створює новий порожній локальний репозиторій у поточній папці.
git clone <url> Копіює вже існуючий проект з віддаленого сервера (наприклад, з GitHub) на твій ПК.
git status Показує поточний стан робочої директорії: які файли змінено, які додано, а які ще не відстежуються.
git add <file> Додає конкретний файл до індексу (staging area) для наступного збереження. git add . додасть усі файли.
git commit -m "опис" Зберігає всі заіндексовані зміни, створюючи "знімок" коду з текстовим коментарем.
git branch <name> Створює нову гілку з вказаним ім'ям для розробки окремого функціоналу.
git checkout <branch> Перемикає робоче серевовище на іншу гілку (або на конкретний старий комміт).
git merge <branch> Об'єднує зміни з вказаної гілки в ту гілку, в якій ти зараз перебуваєш.
git push <remote> <branch> Відправляє всі твої локальні комміти на віддалений репозиторій (наприклад, на GitHub у гілку main).
git pull Завантажує найсвіжіші зміни з віддаленого сервера та одразу об'єднує їх із твоїм локальним кодом.
