Шпаргалка базових команд Bash

Нижче наведено список із 10 найважливіших команд для навігації та роботи з файлами у терміналі Bash:

Команда Що вона виконує
1pwd Виводить повний шлях до поточної робочої директорії.
2ls Показує список файлів та папок у поточній директорії.
3cd <шлях> Переходить до вказаної директорії (папки).
4mkdir <ім'я> Створює нову директорію із зазначеним ім'ям.
5touch <файл> Створює новий порожній файл або оновлює дату модифікації існуючого.
6cat <файл> Виводить вміст файлу безпосередньо у термінал.
7cp <звідки> <куди> Копіює файл або директорію з одного місця в інше.
8mv <звідки> <куди> Переміщує або перейменовує файл чи директорію.
9rm <файл> Видаляє файл. З прапорцем -r видаляє директорію рекурсивно.
10echo "текст" Виводить текст у термінал або записує його у файл через перенаправлення.
