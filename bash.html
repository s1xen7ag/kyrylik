Шпаргалка базових команд терміналу та Git

Нижче наведено список із 10 ключових команд, необхідних для ініціалізації проекту та керування версіями через консольний інтерфейс Bash:

Команда Контекст / Що вона виконує
git initСтворює новий порожній локальний репозиторій у поточній папці.
git statusПоказує стан файлів: які змінено, які додано до індексу розробником.
git add .Додає абсолютно всі нові або змінені файли поточної папки до індексу збереження.
git commit -m "опис"Робить фіксацію (знімок) заіндексованих змін із коментарем.
git branch -M mainПримусово перейменовує поточну головну гілку репозиторію на "main".
git remote add origin <url>Прив'язує локальну папку до віддаленого репозиторію на GitHub.
git push -u origin mainВідправляє локальні комміти у хмару на GitHub і запам'ятовує гілку.
git clone <url>Клонує (завантажує) готовий проект з GitHub у нову папку на ПК.
git logВиводить детальну історію всіх коммітів проекту з їхніми авторами та ID.
git pullПідтягує та автоматично зливає останні зміни з сервера у твій робочий код.
