Шпаргалка базових команд Bash

Нижче наведено список із 10 найважливіших команд для навігації та роботи з файлами у терміналі Bash:

Команда Що вона виконує
1pwdВиводить повний шлях до поточної робочої директорії.
2lsПоказує список файлів та папок у поточній директорії.
3cd шляхПереходить до вказаної директорії (папки).
4mkdir назваСтворює нову директорію із зазначеним ім'ям.
5touch файлСтворює новий порожній файл або оновлює дату модифікації існуючого.
6cat файлВиводить вміст файлу безпосередньо у термінал.
7cp звідки кудиКопіює файл або директорію з одного місця в інше.
8mv звідки кудиПереміщує або перейменовує файл чи директорію.
9rm файлВидаляє файл. З прапорцем -r видаляє директорію рекурсивно.
10echo "текст"Виводить текст у термінал або записує його у файл через перенаправлення.
